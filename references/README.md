# Справочные материалы и референсы (docs/references)

Данная директория содержит справочные файлы, дампы трафика, декомпилированные скрипты и игровые XML-каталоги The Settlers Online, используемые для разработки и верификации логики.

## Структура директории

```
docs/references/
├── amf/                 # Живые дампы AMF-трафика, фикстуры ответов, JSON-схемы и утилиты декодирования (Python)
├── xml/                 # Структурированный каталог игровых XML (212 файлов по разделам: quest, shop, achievements и др.)
├── userscripts/         # Клиентские userscript'ы на JS (референсы логики шахт, бафов, специалистов)
├── client_scripts.txt   # Декомпилированный клиент TSO (ActionScript, ~21.5 МБ) — первоисточник логики
├── icons.xml            # Игровые определения зданий, параметров и productionType
├── globals.xml          # Глобальные параметры, ресурсы, шахты и рецепты
├── en_lang.xml          # Англоязычная локализация игровых сущностей
├── adventure.xml        # Параметры и конфигурация приключений
└── collections.xml      # Параметры коллекций и подбираемых предметов
```

## 1. AMF-трафик и протокол (`amf/`)

Подробная документация: [`amf/README.md`](./amf/README.md)

- **`call01_*` — `call08_*`**: Захваченные пары запрос/ответ реальной сессии игры (бинарные `.bin`, base64 `.b64`, декодированные `.decoded.json`).
- **`call03_response.schema.json`**: Полная структурная схема объекта `dZoneVO` (снапшот зоны).
- **`amf3.py`**: Автономный декодер протокола AMF3 на чистом Python (без внешних зависимостей).
- **`decode.py`**: CLI-утилита для быстрого просмотра и валидации пакетов (`python docs/references/amf/decode.py ...`).
- **`req.txt` / `example-requests.md`**: Сырые логи HTTP/AMF запросов из браузера.

## 2. Игровые XML-каталоги (`xml/`)

Подробная документация: [`xml/README.md`](./xml/README.md)

Каталог из 212 выкачанных XML-файлов клиента игры, разбитых по подпапкам:
- `achievements/` — достижения и награды.
- `advent_calendar/` — события календаря.
- `collections/` — коллекционные предметы.
- `epic_workyard/` — эпические мастерские и рецепты.
- `events/` — ивенты (пасха, хэллоуин, фестивали).
- `quest/` (включая `quest/adventure/` и `quest/event/`) — цепочки заданий и приключений.
- `settings/` — конфигурация клиента и юнитов.
- `shop/` — товары магазина и черного рынка.
- `skill/` — дерево навыков геологов, разведчиков и генералов.

## 3. Пользовательские скрипты (`userscripts/`)

Подробная документация: [`userscripts/README.md`](./userscripts/README.md)

Набор пользовательских скриптов интерфейса (`user_drunken_miner.js`, `user_zoneBuff.js`, `user_generals.js` и др.), используемых как ориентир для сопоставления ID и логики действий в игре.

## 4. Корневые референсы

| Файл | Описание | Применение в проекте |
| --- | --- | --- |
| `client_scripts.txt` | Декомпилированный клиент TSO (ActionScript) | Базовый источник сигнатур методов, форматов VO и кодов команд |
| `icons.xml` | Описания и числовые ID зданий | `ImportProductionCatalog.php`, `config/game.php` |
| `globals.xml` | Константы игры, типы ресурсов | `config/game.php`, сопоставление шахт и руды |
| `en_lang.xml` | Словарь английской локализации | `tso:lang:import` для генерации словарей `lang/` |
| `adventure.xml` | Конфигурация приключений | Справочник по зонам и луту приключений |
| `collections.xml` | Конфигурация коллектиблов | Логика сбора предметов на острове |
