# Gunpowder fix — gpfix-1

## Назначение
Исправить только коллизию складского пороха и одноимённого приключения, сохранив существующий интерфейс и торговый workflow.
База: текущий user_shortcut_trader.js (18e6315 с ранее добавленными двумя минимальными UI-оптимизациями).

## Исправления
- Складской ресурс остаётся Gunpowder; приключение получает уникальный внутренний ключ Adventure_Gunpowder. Оба товара присутствуют в каталоге и picker.
- Для ресурса используется ресурсный lookup, для приключения buff lookup. Не используются неоднозначный GetBitmapData('Gunpowder') и fallback в чужой namespace.
- Отдельные кеши по имени/типу/размеру. Старое имя Gunpowder в сохранённых сделках/шаблонах продолжает означать ресурс. Приключение нужно выбирать отдельно.
- Иконки пороха разрешаются без getItemInfo/getResourceList и без поиска класса ресурса. Нет рекурсивного classifier.
- getResourceList/getItemInfo защищены от повторного входа во время построения каталога. После ошибки guard освобождается в finally.
- Складское количество не складывается с количеством приключений. Приключение без экземпляров в звезде не наследует складской остаток.
- При создании offer/cost VO Adventure_Gunpowder переводится в Adventure + Gunpowder; синтетический ключ не является серверным resourceName. Типы VO/ID сообщений не менялись.

## Что не менялось
Меню, core, settings.json, lifecycle модалей, picker UI, очередь, интервалы, ограничения, уведомления, LocalTradeInjector и init. Кнопка Stop не добавлялась. Другие товары и их цепочки иконок сохранены.

## Проверки
- Node --check: успешно.
- 22 focused regression tests в Node VM с заглушками. Старый код воспроизводит отсутствие Adventure_Gunpowder и buff-иконку складского ресурса.
- Проверено наличие обоих товаров, локализация, независимые иконки/кеши, отсутствующая иконка, typed star fallback, negative cache 60s, отдельные остатки, empty star/warehouse-only, reentrancy и recovery каталога, resource/buff VO и чтение trade VO.
- 1000 повторных обращений к каждой прогретой иконке не добавляют bridge lookups/PNG encode/сканирование каталога в тесте.
- Отдельный picker DOM-тест в локальном Chromium с jQuery 3.6.0 из проекта: обе плитки, две разные иконки и независимые stock badges.
- protected scope проверен: UI/menu/settings/queue/timers/startup не переписаны.
- AIR/SWF/настоящая portable сборка/серверные действия НЕ проверены. Тесты используют заглушки; обещание отсутствия всех лагов или процент ускорения не заявляются.

## Ограничения
Прежние проблемы lifecycle/reload, серверных подтверждений и LocalTradeInjector здесь не переписаны. Совместимость синтетических имён в старом локальном injector и реальных SWF-данных требует ручной проверки. Нет попыток нового протокола и нет реальных торговых запросов во время тестирования.
